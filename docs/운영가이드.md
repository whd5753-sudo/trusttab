# TrustTab 운영 가이드 — 명령 하나로 켜고, Remix 없이 쓰기

TrustTab(구 FairReview)을 매번 터미널에 여러 줄을 치지 않고 쓰는 방법이다.
처음 한 번만 준비하면, 그다음부터는 **아이콘 더블클릭** 또는 **`trusttab` 한 단어**로 끝난다.

## 1. 무엇이 켜져 있어야 하나

| 무엇 | 어디서 | 왜 필요 | 켜는 방법 |
|---|---|---|---|
| 화면 (사이트) | GitHub Pages (인터넷) | 손님 · 사장님 · 관리자가 쓰는 웹사이트 | 항상 켜져 있음. 아무것도 안 해도 됨 |
| 블록체인 (컨트랙트) | Sepolia 테스트넷 | 결제 · 리뷰 · 포인트 기록 | 항상 켜져 있음 |
| MetaMask | Edge 확장 프로그램 | 기록할 때 내 지갑으로 서명 | Edge 를 켜면 같이 켜짐 |
| **AI 오라클 서버** | **내 컴퓨터** (`oracle/`) | 리뷰 점수에 서명 (없으면 리뷰 제출 불가) | **실행기가 켜 줌** ← 이것 때문에 터미널이 필요했다 |
| 화면 개발 서버 | 내 컴퓨터 (`web/`) | 화면 코드를 고칠 때만 | `개발 모드` 로 실행할 때만 |

리뷰를 **읽는 것**은 오라클 없이도 된다. 리뷰를 **블록체인에 제출**할 때만 오라클이 켜져 있어야 한다.

## 2. 실행 방법 세 가지 (아무거나 하나)

### ① 더블클릭 (가장 쉬움)

저장소 폴더(`fairreview-dapp`)에서

- `TrustTab.cmd` → AI 오라클을 켜고 배포 사이트를 Edge 로 연다 (시연 · 평소)
- `TrustTab-dev.cmd` → AI 오라클 + 화면 개발 서버를 켜고 `http://trusttab.localhost:5173/` 을 연다 (화면 고칠 때)

검은 창이 뜨고 `준비 완료` 가 나오면 끝이다. **그 창은 닫지 말고 둔다.** 끝낼 때 그 창에서 `Ctrl+C` 또는 창 닫기.

바탕화면 아이콘을 만들려면 (한 번만, 터미널에서):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-shortcuts.ps1
```

→ 바탕화면에 `TrustTab` · `TrustTab 개발` 아이콘이 생긴다.

### ② 터미널에서 한 단어 `trusttab`

한 번만 (저장소 폴더 터미널에서):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-command.ps1
```

그다음 **새 터미널**(VS Code 터미널 포함, 어느 폴더에서든)에서:

| 입력 | 하는 일 |
|---|---|
| `trusttab` | AI 오라클 + 배포 사이트 열기 |
| `trusttab dev` | AI 오라클 + 화면 개발 서버 + `http://trusttab.localhost:5173/` |
| `trusttab oracle` | AI 오라클만 (브라우저 안 열기) |
| `trusttab --help` | 도움말 |

### ③ npm 명령 (저장소 폴더에서)

| 입력 | 같은 뜻 |
|---|---|
| `npm start` | `trusttab` |
| `npm run dev` | `trusttab dev` |
| `npm run oracle` | `trusttab oracle` |
| `npm test` | 실행기 · 오라클 · 화면 테스트 한 번에 |

## 3. 실행기가 해 주는 일 (`start.mjs`)

1. Node 버전 확인 (20.12 이상)
2. `oracle/.env`(오라클 서명 키)가 **있는지만** 확인 — 내용은 읽지 않는다. 없으면 이유와 할 일을 알려 주고 멈춘다
3. 처음이면 `oracle` · `web` 에 `npm ci` 로 설치
4. AI 오라클이 이미 켜져 있으면 그대로 쓰고, 아니면 켠다 (`[오라클]` 로 시작하는 줄이 오라클 서버의 출력)
5. **블록체인 확인**: 컨트랙트에 등록된 오라클 주소와 지금 켠 오라클 주소가 같은지 본다
   - 같으면 `✔ 컨트랙트에 등록된 오라클과 같습니다`
   - 다르면 `✖ 오라클 주소가 다릅니다` — `oracle/.env` 를 새로 만들었을 때 생기는 문제를 미리 알려 준다
   - 컨트랙트가 긴급 정지 상태면 알려 준다
6. 개발 모드면 화면 개발 서버도 켠다 (5173 번 포트)
7. Edge(MetaMask 가 있는 브라우저)로 사이트를 연다. Edge 가 없으면 기본 브라우저
8. `Ctrl+C` 하면 켠 것을 모두 같이 끈다

배포 사이트 주소는 `.git/config` 의 저장소 이름에서 자동으로 정한다. 저장소 이름을 `trusttab` 으로 바꾸면 `https://whd5753-sudo.github.io/trusttab/` 을 연다.

## 4. MetaMask — 매번 연결하지 않아도 되게

- **처음 한 번**: 사이트에서 `지갑 연결` → MetaMask 창에서 계정 고르고 `연결`. 이것은 MetaMask 보안 규칙이라 생략할 수 없다 (사이트마다 한 번)
- **그다음부터**: 사이트를 열면 창 없이 자동으로 연결된다
- 다른 네트워크에 있으면 연결할 때 `Sepolia 로 전환` 창이 바로 뜬다. 지갑에 Sepolia 가 없으면 `추가` 창이 뜬다
- `연결 끊기` 를 누르면 다음 방문에 자동 연결하지 않고, MetaMask 의 사이트 허락도 거둔다
- 주소가 바뀌면(예: `localhost:5173` → `trusttab.localhost:5173` → GitHub Pages) MetaMask 는 다른 사이트로 보므로 각각 처음 한 번 연결

## 5. Remix 없이 하는 일

| 하던 일 | 이제 | 누가 |
|---|---|---|
| 결제 기록 `recordPayment` | 사이트 → `사장님` 메뉴 (`/owner`) | 사장님 지갑 (Account 2) |
| 보류 리뷰 승인 · 거절 | 바닥글 `관리자: 보류 리뷰 검토` (`/admin`) | 관리자 지갑 (Account 1) |
| 가게 등록 `registerStore` | `/admin` → `운영 설정` (`/admin/ops`) | 관리자 지갑 |
| 긴급 정지 · 다시 켜기 `pause` · `unpause` | `/admin/ops` (한 번 더 확인 후) | 관리자 지갑 |
| 포인트 · 결제 조회 | 머리글 포인트, 사장님 화면 `최근 결제`, Etherscan | 누구나 |

Remix 가 아직 필요한 경우: **컨트랙트를 새로 배포할 때**뿐이다 (컨트랙트 코드를 바꿨을 때). 이때는 새 주소를 `web/src/contracts/fairReview.js` 와 `oracle/config.json` 에 적는다.

새로 등록한 가게가 손님 화면(가게 목록)에 보이려면 `web/src/data/stores.js` 에 같은 번호로 이름 · 분류 · 메뉴를 한 줄 더하고 배포한다 (메뉴는 블록체인에 없는 정보라서).

## 6. 상시 켜 두기 (선택)

Windows 에 로그인할 때마다 AI 오라클이 저절로 켜지게 하려면:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-shortcuts.ps1 -Startup
```

- 작업 표시줄에 최소화된 `TrustTab` 창이 생긴다. 그 창이 오라클이다
- 오라클은 내 컴퓨터 안(`127.0.0.1`)에서만 열리고, 허락한 사이트(`oracle/origins.mjs`)의 요청만 받는다
- 노트북을 들고 다니며 발표할 때 편하다. 대신 컴퓨터가 켜져 있는 동안 서명 키를 쓰는 프로그램이 계속 돈다는 점을 알고 쓴다

모두 되돌리기: `powershell -ExecutionPolicy Bypass -File scripts\uninstall.ps1` (명령 · 바탕화면 아이콘 · 자동 실행을 지운다. 저장소 · `.env` 는 그대로)

## 7. 문제가 생기면

| 보이는 것 | 이유 | 할 일 |
|---|---|---|
| `oracle/.env 가 없습니다` | 서명 키 파일이 없음 | 10단계에서 만든 `.env` 를 `oracle/` 에 넣는다. 새로 만들면(keygen) 컨트랙트와 맞지 않는다 |
| `오라클 주소가 다릅니다` | `.env` 를 새로 만들었음 | 예전 `.env` 를 찾거나, 새 오라클 주소로 컨트랙트를 다시 배포 |
| `오라클 서버가 멈췄습니다 … 8787` | 다른 창에서 오라클이 이미 켜져 있거나 다른 프로그램이 포트 사용 | 다른 터미널 창을 닫고 다시 실행 |
| `화면 개발 서버가 멈췄습니다 … 5173` | 다른 창에서 `npm run dev` 가 켜져 있음 | 그 창을 `Ctrl+C` 로 끄고 다시 실행 |
| `블록체인에 접속하지 못해 …` | 인터넷 끊김 · 공개 노드 장애 | 인터넷 확인. 오라클은 그래도 켜져 있다 |
| 사이트에서 `AI 오라클 서버에 연결할 수 없습니다` | 오라클이 꺼져 있음 | 실행기를 켠다 |
| `trusttab` 을 모른다고 함 | 새 터미널이 아니거나 설치를 안 함 | 터미널을 새로 열거나 `install-command.ps1` 실행 |
| `이 시스템에서 스크립트를 실행할 수 없으므로` | PowerShell 실행 정책 | 명령 앞에 `powershell -ExecutionPolicy Bypass -File` 을 붙여 실행 (위 예시처럼) |
| 사이트가 예전 모양 | 브라우저 캐시 | `Ctrl+F5` |
