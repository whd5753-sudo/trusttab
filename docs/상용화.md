# TrustTab 상용화 — 지금 적용한 것과 실제 출시에 더 필요한 것

TrustTab(구 FairReview)은 수업 실습 서비스다 (Sepolia 테스트넷 · 실제 돈 없음).
이 문서는 **일반 웹 서비스처럼 보이고 동작하게 지금 적용한 기능**과, **진짜로 출시하려면 더 필요한 것**을 나눠 정리한다.

## 1. 한눈에

| 분야 | 지금 (11단계) | 실제 출시라면 |
|---|---|---|
| 이름 · 브랜드 | TrustTab 이름 · 로고 · 아이콘 · 탭 제목 | 상표 검색 · 등록 (KIPRIS) |
| 주소 | `trusttab.localhost` · `github.io/trusttab` | 내 도메인 (예: trusttab.kr) + HTTPS |
| 실행 | 더블클릭 · `trusttab` 한 단어 · 로그인 자동 실행 | 오라클을 24시간 서버(클라우드)로 |
| 지갑 | 자동 재연결 · Sepolia 자동 전환/추가 · MetaMask 우선 | 이메일 · 소셜 로그인 지갑, 수수료 대신 내기 |
| 운영 | 사장님 결제 기록 · 관리자 승인 · 가게 등록 · 긴급 정지 화면 | 관리자 여러 명(멀티시그) · 신고 · 고객센터 |
| 공유 · 검색 | 미리보기 이미지 · 설명 · sitemap · robots · noindex | 가게마다 미리보기 · 서버 렌더링 · 검색 등록 |
| 앱 | 홈 화면에 설치 (manifest · 아이콘) | 알림 · 오프라인 |
| 보안 | CSP · 오라클 허락 주소 · 입력 검사 · 키 분리 | 외부 감사 · 키 금고(KMS) · 요청 제한 · 버그 바운티 |
| 접근성 | 건너뛰기 · 초점 이동 · 대비 4.5:1 · 움직임 줄이기 | 전문 접근성 점검 |
| 안정성 | 오류 화면 · 인터넷 끊김 안내 · 로딩/빈/오류 상태 | 장애 감시 · 오류 수집 |
| 법 · 정책 | 이용약관 · 개인정보처리방침 (실습용) | 법률 검토 · 사업자 정보 · 책임자 지정 |
| 품질 | 테스트 web 71 · oracle 5 · 실행기 4 · contracts 39 · 뮤테이션 | + 실제 사용자 시험 · 부하 시험 |

## 2. 지금 적용한 기능 — 무엇을 · 왜 · 어디서 · 어떻게 확인

### 2-1. 이름 · 브랜드

- **무엇**: 화면 이름 TrustTab (Tab = 계산서: 믿을 수 있는 계산서가 있는 손님만 리뷰). 로고 `T` + 확인 표시, 탭 아이콘, 홈 화면 아이콘
- **바꾸지 않은 것**: 컨트랙트 이름 `FairReview`, 서명 태그 `FairReview.AIVerdict.v1`. 바꾸면 다시 배포해야 하고 이미 남긴 리뷰 · 서명과 맞지 않는다. 사용자에게 보이는 이름과 내부 이름은 따로 가도 된다
- **어디**: `web/src/components/Layout.jsx`, `web/public/icon.svg` 외 아이콘, `web/index.html`
- **확인**: 브라우저 탭 · 즐겨찾기 아이콘, 화면마다 탭 제목(`온정 김치찌개 · TrustTab`)

### 2-2. 주소

- **내 컴퓨터**: `http://trusttab.localhost:5173/` — `*.localhost` 는 Edge · Chrome 이 자동으로 내 컴퓨터에 연결한다 (hosts 파일 수정 없음). MetaMask 도 안전한 주소로 인정한다
- **배포**: 저장소 이름을 `trusttab` 으로 바꾸면 `https://whd5753-sudo.github.io/trusttab/`. 저장소 이름을 코드에 적지 않고 GitHub Actions 가 알려 주는 값에서 읽는다 (`web/vite.config.js`)
- **내 도메인을 쓰려면** (돈이 든다, 연 1~3만 원 정도):
  1. 도메인 구입 (예: 가비아 · 후이즈 · Cloudflare)
  2. GitHub 저장소 Settings → Pages → Custom domain 에 입력
  3. 도메인 관리 화면에서 CNAME `whd5753-sudo.github.io` 설정 → Enforce HTTPS 체크
  4. 주소 맨 앞이 바뀌므로 `VITE_BASE=/` 로 빌드하고, 오라클 허락 주소(`oracle/origins.mjs`)에 새 주소 추가

### 2-3. 링크 공유 미리보기 (Open Graph)

- **무엇**: 카카오톡 · 메신저 · SNS 에 주소를 붙이면 제목 · 설명 · 1200×630 그림이 나온다
- **어디**: `web/index.html` 의 `og:` · `twitter:` 줄, `web/public/og.png`
- **확인**: 배포 후 카카오톡 나에게 보내기로 주소 붙이기 (카카오는 미리보기를 오래 기억하므로 바꾼 뒤엔 카카오 개발자 사이트의 '공유 디버거'로 새로 고침)
- **한계**: 한 장짜리 앱(SPA)이라 가게마다 다른 미리보기는 안 된다 → 실제 출시라면 서버 렌더링이나 가게별 정적 페이지

### 2-4. 앱처럼 설치 (웹 앱 매니페스트)

- **무엇**: Edge 주소창의 `앱 설치` 아이콘, 휴대폰 `홈 화면에 추가` 로 아이콘이 생기고 주소창 없는 창으로 열린다
- **어디**: `web/public/manifest.webmanifest`, 아이콘 192 · 512 · 마스크용 512 · 애플 180
- **넣지 않은 것**: 오프라인 캐시(서비스 워커). 넣으면 새 버전을 배포해도 예전 화면이 남는 문제가 생겨, 수업 중 자주 고치는 지금은 빼는 게 안전하다

### 2-5. 검색

- **무엇**: 설명문(description) · 대표 주소(canonical) · `robots.txt` · `sitemap.xml` (빌드할 때 주소에 맞게 자동 생성), 관리자 · 사장님 화면은 `noindex`(검색에 안 나오게)
- **한계**: GitHub Pages 의 하위 폴더 주소에서는 검색 엔진이 `robots.txt` 를 맨 앞 주소에서만 읽는다 → 내 도메인을 쓰면 제대로 동작. 검색에 빨리 나오게 하려면 Google Search Console · 네이버 서치어드바이저에 sitemap 주소를 등록

### 2-6. 보안

| 항목 | 내용 | 확인한 방법 |
|---|---|---|
| 보안 정책(CSP) | 배포 화면은 이 사이트 · 공개 블록체인 노드 · 내 컴퓨터 오라클에만 접속. 다른 곳으로 몰래 보내는 코드가 들어와도 브라우저가 막음 | Chromium 에서 example.com 요청이 막히는 것 확인 |
| 오라클 허락 주소 | `oracle/origins.mjs` 에 적은 주소만 서명 요청 가능, 앞부분만 같은 가짜 주소 · 다른 포트는 거절 | 테스트 O5, 실제 403 확인 |
| 개인키 | `oracle/.env` 는 커밋 · Claude 읽기 금지, 실행기도 있는지만 확인. 지갑 키는 MetaMask 밖으로 나오지 않음 | CI 의 .env 검사 |
| 입력 검사 | 손님 · 사장님 주소 형식, 셀프 결제, 금액 범위, 가게 이름, 리뷰 링크 번호를 MetaMask 전에 검사. 최종 판단은 컨트랙트 | 테스트 S10 · S11 · S14 · S20 |
| 위험한 조작 확인 | 긴급 정지는 한 번 더 묻는다 | 테스트 S21 |
| 지갑 끊기 | 화면만이 아니라 MetaMask 의 사이트 허락까지 거둠 | 테스트 S5 |
| 리퍼러 | 다른 사이트로 갈 때 주소 전체를 넘기지 않음 | `index.html` |

### 2-7. 접근성 (누구나 쓸 수 있게)

- 키보드 `Tab` 을 누르면 첫 칸에 `본문으로 건너뛰기`
- 다른 화면으로 가면 맨 위로 + 본문에 초점 (화면 낭독기가 새 내용부터 읽음)
- 글자 대비 4.5:1 이상, 초점 테두리, 색만이 아니라 글자로도 판정 표시
- 컴퓨터의 '움직임 줄이기' · '투명도 줄이기' · 고대비 모드를 따름

### 2-8. 안정성 · 안내

- 화면 오류가 나도 하얀 화면 대신 안내 카드 (오류 원문은 숨김), 머리글 · 메뉴는 그대로
- 인터넷이 끊기면 위에 노란 안내, 다시 연결되면 사라짐
- 블록체인 읽기마다 '불러오는 중 · 실패(다시 시도) · 비어 있음' 세 상태
- 지갑이 없으면 PC 는 MetaMask 설치 링크, 휴대폰은 MetaMask 앱에서 열기 링크

### 2-9. 속도

- 자주 안 바뀌는 라이브러리(react · ethers)를 따로 묶어, 화면만 고쳐 다시 배포해도 방문자는 큰 파일을 다시 받지 않는다 (500kB 경고 해결)
- 이미지는 압축(PNG 최적화), 글꼴은 컴퓨터 기본 글꼴(맑은 고딕)이라 받을 파일 없음

### 2-10. 약관 · 개인정보

- `/terms` 이용약관 · `/privacy` 개인정보처리방침 — **실제로 하는 것만** 적었다 (회원 가입 없음, 쿠키 · 분석 도구 없음, 블록체인에 공개되는 것, 오라클 · 공개 노드 · GitHub 로 가는 것, 브라우저에 저장하는 값 하나)
- 수업 실습용 안내문이다. 실제 출시라면 법률 검토가 필요하다 (4절)

### 2-11. 지갑을 덜 귀찮게

- 처음 한 번만 연결하면 다음부터 창 없이 자동 연결
- 다른 네트워크면 연결하자마자 Sepolia 전환, 지갑에 없으면 추가
- 확장 프로그램이 여러 개여도 MetaMask 를 먼저 (EIP-6963)

### 2-12. 운영 화면 (Remix 없이)

- `/owner` 사장님: 결제 기록 → 결제 번호 + **리뷰 링크**(손님이 누르면 결제 번호가 미리 채워짐) + 최근 결제 20건 · 리뷰 작성 여부
- `/admin` 관리자: 보류 리뷰 승인 · 거절
- `/admin/ops` 관리자: 운영 상태(정상/정지), 등록된 가게, **가게 등록**, **긴급 정지 · 다시 켜기**

### 2-13. 실행 · 자동 실행

- `TrustTab.cmd` 더블클릭, `trusttab` 한 단어, `npm start` — 오라클을 켜고 사이트를 연다
- 켤 때 **컨트랙트에 등록된 오라클과 같은 키인지** 블록체인에서 확인 → 가장 흔한 실수(키를 새로 만듦)를 미리 알려 줌
- 로그인할 때 자동 실행(선택) · 모두 되돌리기 스크립트
- 자세히: [운영가이드](운영가이드.md)

### 2-14. 품질

- 테스트: web 71 (화면 · 체인 mock · 사이트 기능) · oracle 5 · 실행기 4 · contracts 39
- 11단계 새 기능 14개를 하나씩 지워 봐서 14개 모두 테스트가 잡는 것을 확인 (테스트가 기능을 진짜로 지킴)
- push 하면 CI 4개 작업, 테스트가 통과해야만 배포

## 3. 직접 확인해 보기 (5분)

1. Edge 로 배포 사이트를 열고 `F12` → `Lighthouse` → `분석` — 성능 · 접근성 · 권장사항 · 검색 점수가 나온다
2. 주소창 오른쪽 `앱 사용 가능` 아이콘 → 설치 → 시작 메뉴에 TrustTab
3. `F12` → `콘솔` 에 빨간 `Content Security Policy` 오류가 없는지
4. 마우스 없이 `Tab` 키만으로 리뷰 쓰기 → 검사하기까지 되는지
5. 카카오톡 나에게 보내기로 주소 붙여 미리보기 그림 확인
6. 와이파이를 껐다 켜며 노란 안내가 나왔다 사라지는지

## 4. 실제로 출시하려면 더 필요한 것 (우선순위 순)

> 법 · 규제 항목은 방향만 적었다. 실제 출시 전에는 변호사 등 전문가 확인이 필요하다.

### 꼭 (출시 전)

| 할 일 | 왜 | 방법 예시 |
|---|---|---|
| 진짜 결제 확인 (카드사 · PG 서명) | 지금은 사장님이 판매 없이 결제를 기록할 수 있다 (보안점검 T2) | PG 사가 결제 완료에 서명 → 컨트랙트가 그 서명을 확인 (오라클과 같은 구조) |
| 오라클을 서버로 + 키 금고 | 지금은 내 컴퓨터가 꺼지면 리뷰 제출 불가, 키는 파일 | 클라우드 서버 24시간 · 키는 KMS/HSM · 요청 제한 · 기록 |
| 오라클 여러 개 · 관리자 멀티시그 | 키 하나가 털리면 끝 (보안점검 T3) | 2-of-3 서명, 관리자 Safe 지갑 |
| 리뷰 원문은 체인 밖 | 블록체인은 지울 수 없어 개인정보 삭제 요청에 대응 불가 (T4) | 원문은 DB, 체인에는 해시만 |
| 외부 보안 감사 | Slither · 뮤테이션은 기본 점검일 뿐 | 감사 업체 · 버그 바운티 |
| 법률 검토 | 개인정보 처리, 사업자 정보 표시, 리뷰 · 광고 표시 규칙, 포인트가 돈처럼 쓰이면 금융 규제 가능성 | 전문가 검토 후 약관 · 방침 다시 쓰기, 개인정보 보호책임자 지정 |
| 상표 확인 | TrustTab 이 이미 등록된 이름일 수 있다 | KIPRIS 검색 · 출원 |

### 하면 좋음 (출시 직후)

| 할 일 | 왜 |
|---|---|
| 메인넷 또는 저렴한 L2 선택 + 수수료 대신 내기(paymaster) | 손님이 ETH 없이도 리뷰를 쓰게 |
| 이메일 · 소셜 로그인 지갑 | MetaMask 설치가 가장 큰 진입 장벽 |
| 가게 정보 관리 화면 (메뉴 · 사진) | 지금은 `stores.js` 를 고쳐 배포해야 함 |
| 리뷰 신고 · 사장님 답글 | 분쟁 처리 |
| 장애 감시 · 오류 수집 | 문제가 생긴 걸 사용자보다 먼저 알기 (개인정보 · 동의 고려) |
| 이벤트 색인(인덱서) | 리뷰가 많아지면 공개 노드로 전부 읽기 느림 |
| 가게별 공유 미리보기 · 서버 렌더링 | 검색 · 공유에 가게 이름이 나오게 |
| 고객센터 · 자주 묻는 질문 | 지갑 · 수수료 질문 대응 |

### 나중에

알림(새 리뷰 · 승인), 오프라인, 다국어, 통계 화면(사장님용), 포인트 혜택(쿠폰) — 포인트를 혜택으로 바꾸기 시작하면 규제 검토부터.
